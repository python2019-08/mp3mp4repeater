# Python 复刻【一心复读机 AB复读功能】桌面版（支持 MP3 / MP4）
先说明整体方案：
- 核心对标：**AB打点、A/B左右微调、重置AB、倍速播放、时间轴拖动、播放暂停快进快退**（就是第一张图的AB模式核心功能）
- 技术栈：`PyQt6`（UI） + `ffmpeg` + `pyav`（音视频解码播放） + `soundtouch`（变速不变调，这个是复读机刚需！）
> 为什么不用 pygame？pygame 对 mp4 视频支持很差，倍速也不好做；pyav 封装ffmpeg，音视频通用，mp3/mp4都能播。
> 难点重点：**精确时间跳转、AB区间循环、毫秒级微调、变速不变调**，这也是一心复读机最核心的地方。

> ⚠️ 前置依赖：系统需要安装 ffmpeg（pyav 依赖它）

## 1. 先安装依赖
```bash
# 1. 创建环境
conda create -n av python=3.12
# 2. 激活环境
conda activate av
#  conda deactivate
# 3.安装依赖
sudo apt install libsoundtouch-dev # 先装soundtouch系统库
pip install pyqt6 av pysoundtouch soundfile
```
> soundtouch 用来实现变速不变调，是复读机的灵魂；av 是ffmpeg的python绑定，处理mp3/mp4。

## 3. 当前版本的局限 & 后续扩展路线（对标一心复读机）
> 当前代码是**最小原型**，先把AB循环跑通，还有几个核心短板，也是一心复读机做得好的地方：
1. ❗音频播放部分我简化了：现在只解码，**没有真正播放音频**（上面代码只处理视频画面，音频输出需要加 `pyaudio` 播放 soundtouch 处理后的音频）
2. 没有字幕支持（srt加载，字幕断句）
3. 没有闪播、录音跟读、收藏片段
4. 音频同步精度还有优化空间（音视频同步是复读机最大坑）

### 补全音频播放（推荐方案）
加 `pyaudio`，把 av 解码出来的音频送到 soundtouch 变速，再推给声卡播放，这是标准链路：
`av解码音频 → soundtouch变速 → pyaudio输出`

### 推荐扩展顺序（一步步靠近一心复读机）
1. 第一步：补全音频播放 + 音视频同步（最重要）
2. 第二步：增加SRT字幕加载、字幕显示
3. 第三步：增加【闪播】（短区间高速循环）
4. 第四步：增加录音跟读（pyaudio录制麦克风）
5. 第五步：增加智能断句（调用ASR，比如faster-whisper，自动切句子，对应一心复读机的智能断句）

## 4. 备选方案（如果你不想自己啃音视频同步大坑）
如果你不想自己处理音视频同步，有一个偷懒路线：
使用 `mpv` + `python-mpv`，mpv本身自带精准AB循环、变速不变调，底层非常成熟，很多复读软件都是套mpv。
- 库：`python-mpv`
- 优点：一行命令开启AB循环、音视频同步稳、mp3/mp4通吃
- 缺点：需要系统安装mpv
